# QA Regression Manager

Локальное приложение для каталогов проверок, регрессионных прогонов и истории результатов. Каталоги содержат тесты с заголовками и упорядоченными шагами; проверки и шаги можно редактировать и переставлять. Платформы выбираются при создании регресса: Android, iOS, adaptive android, adaptive iOs и WEB. Данные хранятся в IndexedDB текущего браузера.

## Запуск

Требуется Node.js 20 или новее.

```bash
npm install
npm run dev
```

Откройте адрес Vite из терминала. Для production-сборки выполните `npm run build`, для локального просмотра сборки — `npm run preview`.

Каталоги, проверки, регрессы и результаты хранятся локально в IndexedDB текущего браузера. Создавайте и редактируйте данные через интерфейс приложения; для доступа к ним используйте тот же браузер и адрес приложения.

## Импорт и экспорт

На странице «Импорт / экспорт» можно выбрать `.xlsx`: приложение строит предварительный отчёт по листам, сохраняет встроенные изображения и показывает неоднозначные записи до подтверждения.

- «Объединить» обновляет строки с тем же источником и оставляет остальные записи каталога.
- «Заменить» удаляет только текущие записи каталога; история прогонов сохраняется.
- Неоднозначные строки и исходные значения статусов видны в отчёте и не нормализуются автоматически.

Прогон создаётся для одного из двух каталогов. Из него можно выгрузить `.xlsx`; полную базу с изображениями — в JSON-резервную копию.

## Данные

Каталог, материалы книги, снимки проверок в регрессах и результаты платформ хранятся отдельно. Изменение каталога не меняет уже созданные прогоны.
